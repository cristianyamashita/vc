# Hollywood images — sources and licenses

Used by `page/misc/hollywood.html` in the `satview` and `facematch` panes.
Every file here is public domain, so it can be shipped without attribution
obligations. The sources are listed anyway.

## How the files were prepared

Each original was converted to grayscale, auto-contrasted (1% cutoff) and
resized with Pillow: aerial images to at most 1400 px on the long side (JPEG
quality 74), faces to 512×512 (JPEG quality 80). The page tints them at run
time with the colors of the active scheme, so no color is needed in the files.
