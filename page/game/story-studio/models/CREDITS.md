# Model credits

Every `.glb` here must name where it came from and under what licence.
Prefer CC0 / public domain sources so the files can be committed without
attribution obligations.

| file | source | licence |
|---|---|---|
| `crate.glb` | generated by `scripts/` for this repository | CC0 / public domain |

`crate.glb` is a plain unit cube. It exists so the glTF loading path — file
fetch, cache, per-placement clone, and the offline manifest's `models` bucket —
is exercised by a real file rather than assumed to work. Replace or delete it
once real props land.
