Wheel Picker help

Spin a large wheel and save different lists by URL hash.

How it works

  • Press Spin to turn the wheel.
  • The arrow on the right marks the selected item.
  • Use Edit items to change the list.
  • One item per line. Minimum 2, maximum 60.
  • In custom mode, write items like #c1c1ca:My label or tomato:My label.
  • Change the URL hash to save another wheel.
  • Press ? to open this help.
